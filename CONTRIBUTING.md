# Contributing to PDFCraft

Thanks for improving PDFCraft.

1. Use Python 3.10+ and create a virtual environment.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Keep changes focused and preserve offline-first behavior.
4. Never weaken the default no-overwrite protection without a strong reason.
5. Add or update tests for behavioral changes.
6. Run `ruff check .` and `pytest` before proposing a change.
7. Update both English and Arabic README sections when user-facing behavior changes.

Do not commit real private PDFs, credentials, passwords, tokens, or generated build artifacts.
